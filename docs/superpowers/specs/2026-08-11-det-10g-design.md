# Det10g Model Wrapper Design

**Date:** 2026-08-11  
**Status:** Approved for implementation (manual test by user)  
**Approach:** A — thin `Engine` subclass mirroring `Yolov5`, reuse `GenerateProposalsScrfd`

## Goal

Add a face-detection model class for InsightFace buffalo_l `det_10g` (SCRFD), matching the existing `Yolov5` encapsulation pattern: inherit `Engine`, implement `Postprocess`, expose box + 5 landmarks.

## Non-goals

- Do not change `InfProcess`, `main_rtsp`, or `main_img`
- Do not add a new demo binary
- Do not wrap other buffalo_l models (`w600k_r50`, `genderage`, etc.)
- No automated test suite; validation is **manual** by the user

## Context

- Model artifact: `model/det_10g.axmodel` (640×640, ~7 ms on device per `model/readme.txt`)
- ONNX twin: `common/buffalo_l/det_10g.onnx` / `model/buffalo_l/det_10g.onnx`
- Observed axmodel outputs (9 tensors):

| Name (id) | Shape | Role | Stride |
|-----------|-------|------|--------|
| 448 | [12800, 1] | score | 8 |
| 451 | [12800, 4] | bbox | 8 |
| 454 | [12800, 10] | kps | 8 |
| 471 | [3200, 1] | score | 16 |
| 474 | [3200, 4] | bbox | 16 |
| 477 | [3200, 10] | kps | 16 |
| 494 | [800, 1] | score | 32 |
| 497 | [800, 4] | bbox | 32 |
| 500 | [800, 10] | kps | 32 |

`N = (640/stride)^2 * 2` (2 anchors per cell).

- Existing helper: `detection::GenerateProposalsScrfd` (expects CHW-style blobs)
- Landmark letterbox reverse: use `detection::GetOutBbox` (already maps `landmark[5]`)

## API

```cpp
// nodes/det_10g.h
class Det10g : public Engine {
 public:
  explicit Det10g(const std::string& model_config);
  ~Det10g() override;
  int Postprocess(int pic_width, int pic_height,
                  std::vector<detection::Object>& objects) override;
  Det10g(const Det10g&) = delete;
  Det10g& operator=(const Det10g&) = delete;
};
```

Usage (same as Yolov5):

```cpp
Det10g det("");
det.Init();
det.Process(nchw_or_packed_input);
std::vector<detection::Object> objects;
det.Postprocess(src_w, src_h, objects);
// objects[i].rect, objects[i].prob, objects[i].landmark[0..4]
```

## Defaults

Applied when constructing / initializing `Det10g` (override `EngineConfig` fields; do not change global Yolov5 fire defaults for other classes):

| Field | Value |
|-------|--------|
| `model_file` | `model/det_10g.axmodel` |
| `model_type` | `det_10g` |
| `inputs` | `{1, 3, 640, 640}` |
| `prob_threshold` | `0.5` |
| `nms_threshold` | `0.4` |
| `strides` | `{8, 16, 32}` |
| `labels` | `{"face"}` |

`EngineConfig::Init()` may remain a stub; Det10g must apply defaults **before** `Engine::Init()` loads `config_.model_file`.

**Required small Engine change:** today `config_` is `private`, so a subclass cannot set `model_file` / thresholds. Prefer the least invasive option:

1. Change `config_` to `protected`, **or**
2. Add `protected: void SetConfig(const EngineConfig&)` / `EngineConfig& MutableConfig()`,

then Det10g ctor calls it with the defaults above. Do **not** change the global `EngineConfig` default fire model used by Yolov5.

## Postprocess algorithm

1. Require `GetInfo()->nOutputSize == 9`; else return error.
2. Group outputs by element count into strides `{8,16,32}`:
   - score: `N * 1 * sizeof(float)`
   - bbox: `N * 4 * sizeof(float)`
   - kps: `N * 10 * sizeof(float)`
3. For each stride, convert packed `[N, C]` → CHW layout expected by `GenerateProposalsScrfd`:
   - score → `[2, H*W]`
   - bbox → `[8, H*W]`
   - kps → `[20, H*W]` (2 anchors × 10)
4. If current `GenerateProposalsScrfd` kps indexing ignores anchor `q`, apply a **minimal fix** so landmarks use `(q * 10 + c) * feat_size + index` (or equivalent). Document the fix in the PR/commit.
5. Accumulate proposals; call `detection::GetOutBbox(proposals, objects, nms, 640, 640, pic_h, pic_w)`.
6. Optionally set `objects[i].model = "det_10g"`.

Return `0` on success; negative codes on size/layout mismatch (mirror Yolov5’s `-1` / `-2` style).

## Manual test plan (owner: user)

1. Build Release `ax_core`.
2. Load a face image (or YUV frame already resized/letterboxed to 640×640 as Engine expects).
3. Construct `Det10g("")`, `Init()`, `Process()`, `Postprocess(w,h,objects)`.
4. Confirm faces have reasonable boxes and 5 landmarks; empty scenes return empty `objects`.
5. Confirm no crash on Init failure (missing model path).

## Open risks

- Output tensor **order** from AX runtime may not match numeric id order; grouping by **buffer size** avoids relying on name order.
- Packed→CHW conversion must match how the ONNX was exported (anchor-major vs location-major). If manual test shows shifted boxes, fix conversion first before changing thresholds.
